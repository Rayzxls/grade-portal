# Skill.md

รายการ Skills ที่ใช้งานได้ในโปรเจกต์นี้ผ่าน Claude Code

## วิธีเรียกใช้

พิมพ์ `/<skill-name>` ใน Claude Code เพื่อเรียกใช้ skill ที่ต้องการ

## หมวด Engineering

| Skill | คำอธิบาย |
|-------|----------|
| `engineering:architecture` | สร้างหรือประเมิน Architecture Decision Record (ADR) |
| `engineering:system-design` | ออกแบบระบบ บริการ และสถาปัตยกรรม |
| `engineering:tech-debt` | ระบุและจัดลำดับความสำคัญของ technical debt |
| `engineering:standup` | สร้าง standup update จากกิจกรรมล่าสุด |
| `engineering:testing-strategy` | ออกแบบ test strategy และ test plan |
| `engineering:deploy-checklist` | Checklist ก่อน deploy production |
| `engineering:incident-response` | จัดการ incident และเขียน postmortem |
| `engineering:debug` | Debug แบบมีโครงสร้าง |
| `engineering:documentation` | เขียนเอกสารทางเทคนิค |
| `engineering:code-review` | Review โค้ดด้าน security, performance, correctness |
